# Safe Driving Gamified Insurance App UI/UX Design System

**Author:** Manus AI
**Purpose:** To establish a consistent, modern, and sleek visual language for the Safe Driving Gamified Insurance App, ensuring a world-class user experience. This document outlines the core design principles, typography, color palette, and foundational UI components.

## Design Principles

1.  **Clarity & Simplicity:** Information should be easy to understand at a glance. Avoid clutter and unnecessary elements.
2.  **Modern & Sleek:** Utilize clean lines, ample whitespace, and subtle animations to create a contemporary feel.
3.  **Trust & Transparency:** Visuals should convey reliability and honesty, especially around scoring and savings. Use clear, legible typography and a balanced color palette.
4.  **Engaging & Rewarding:** Incorporate gamification elements (points, streaks, badges) in a visually appealing and motivating way, without being distracting.
5.  **User-Centric:** Prioritize ease of use, intuitive navigation, and accessibility for all drivers.

## Typography

**Primary Font:** Inter (or similar modern sans-serif font like Montserrat, Lato)
*   **Usage:** Headings, body text, and UI elements.
*   **Rationale:** Inter is highly legible, versatile, and has a modern, clean aesthetic that scales well across different screen sizes.

**Font Weights:**
*   Light (300): For subtle text, secondary information.
*   Regular (400): For body text, standard labels.
*   Medium (500): For emphasis, subheadings.
*   Semi-Bold (600): For primary headings, key call-to-actions.
*   Bold (700): For strong emphasis, critical information.

**Font Sizing (Example - Mobile Base):**
*   H1 (Display): 28-32px
*   H2 (Section Title): 22-24px
*   H3 (Card Title): 18-20px
*   Body Large: 16px
*   Body Regular: 14px
*   Caption/Small: 12px

## Color Palette

The color palette is designed to be modern, trustworthy, and engaging, using a primary accent color for key actions and gamified elements, complemented by a neutral base and semantic colors for feedback.

| Category | Color Name | Hex Code | Usage |
|---|---|---|---|
| **Primary Accent** | Deep Teal | `#008080` | Primary call-to-actions, gamification highlights, progress indicators |
| **Secondary Accent** | Vibrant Orange | `#FF8C00` | Secondary actions, warnings, complementary gamification elements |
| **Neutral Base** | Dark Grey | `#2C3E50` | Primary text, backgrounds, card elements |
| | Medium Grey | `#7F8C8D` | Secondary text, borders, inactive states |
| | Light Grey | `#ECF0F1` | Backgrounds, separators, subtle UI elements |
| **Semantic - Success** | Forest Green | `#2ECC71` | Positive feedback, safe driving indicators |
| **Semantic - Warning** | Amber | `#F39C12` | Moderate risk, areas for improvement |
| **Semantic - Danger** | Crimson Red | `#E74C3C` | High risk, unsafe driving events |

## UI Components (Foundational)

These are the basic building blocks that will be used consistently throughout the app.

*   **Buttons:** Primary (Deep Teal), Secondary (outlined), Tertiary (text-only).
*   **Cards:** Used for displaying trip summaries, gamification progress, and savings insights. Clean, rounded corners, subtle shadows.
*   **Navigation:** Bottom tab bar for primary navigation (Dashboard, Trips, Rewards, Profile).
*   **Input Fields:** Clean, minimal design with clear labels and focus states.
*   **Progress Indicators:** Circular progress bars for overall score, linear bars for mission progress.
*   **Icons:** Modern, line-art style icons for clarity and visual appeal.

## Imagery and Illustrations

*   **Style:** Abstract, geometric, or minimalist illustrations to convey concepts without being overly literal. Avoid stock photography.
*   **Purpose:** To enhance onboarding, celebrate achievements, and explain complex concepts visually.

## Animations and Transitions

*   **Subtle & Purposeful:** Animations should enhance the user experience, providing feedback and guiding attention, rather than distracting. Examples: smooth transitions between screens, subtle feedback on button taps, progress updates.
